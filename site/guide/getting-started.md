# Installation and requirements

Cobblemon XP Overhaul adds configurable experience rewards for captures and battles, with an **XP Flask** for Pokémon training.

## Supported versions

| Component | Requirement |
| --- | --- |
| Minecraft | **1.21.1** |
| Cobblemon XP Overhaul | **2.1** |
| Cobblemon | **1.8.2 up to, but not including, 1.9.0**, for Minecraft 1.21.1 |
| Loader | **Fabric** or **NeoForge** |
| OS Cobblemon Library | **1.3.0+**, required |
| Java | **21** |

### Fabric

Use the **Fabric** JAR with Fabric Loader **0.17.2+**, Fabric API, Fabric Language Kotlin **1.13.6+**, Cobblemon **1.8.2+ (below 1.9)**, **OS Cobblemon Library 1.3.0+**, and Cloth Config **15.0.140+**. Mod Menu is optional.

### NeoForge

Use the **NeoForge** JAR with NeoForge **21.1.182+**, Cobblemon **1.8.2+ (below 1.9)**, **OS Cobblemon Library 1.3.0+**, and, for the client configuration UI, Cloth Config **15.0.140+**. The build uses Kotlin for Forge. Never mix Fabric and NeoForge builds.

## Installation

1. Install Minecraft 1.21.1, a supported loader, and Cobblemon.
2. Get the appropriate XP Overhaul build from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/cobblemon-xp-overhaul).
3. Place the mod JAR and required dependencies, including OS Cobblemon Library, in the mods folder. Multiplayer servers and clients need the matching loader build.
4. Start the game or server to generate the default files in `config/cobblemon_xp_overhaul/`.
5. Catch a Pokémon and complete a battle to observe the rewards.

::: info Source and public release
The source identifies **v2.1**. Check CurseForge for the actual published files before installing.
:::

Use **sneak + right-click** on your summoned Pokémon while holding the XP Flask to preview a transfer without using XP. Read [XP progression](/guide/progression), [XP Flask](/guide/xp-flask) and [configuration](/guide/configuration).
