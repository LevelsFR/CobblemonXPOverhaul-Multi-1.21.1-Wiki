# Installation and requirements

Cobblemon XP Overhaul adds configurable experience rewards for captures and battles, with an **XP Flask** for Pokémon training.

## Supported versions

| Component | Requirement |
| --- | --- |
| Minecraft | **1.21.1** |
| Cobblemon XP Overhaul | **2.0** |
| Cobblemon | **1.8.0+**, for Minecraft 1.21.1 |
| Loader | **Fabric** or **NeoForge** |
| Java | **21** |

### Fabric

Use the **Fabric** JAR with Fabric Loader **0.17.2+**, Fabric API, Fabric Language Kotlin **1.13.6+**, Cobblemon and Cloth Config **15.0.140+**. Mod Menu is optional.

### NeoForge

Use the **NeoForge** JAR with NeoForge **21.1.182+**, Cobblemon and, for the client configuration UI, Cloth Config **15.0.140+**. The build uses Kotlin for Forge. Never mix Fabric and NeoForge builds.

## Installation

1. Install Minecraft 1.21.1, a supported loader, and Cobblemon.
2. Get the appropriate XP Overhaul build from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/cobblemon-xp-overhaul).
3. Place the mod JAR and required dependencies in the mods folder. Multiplayer servers and clients need the matching loader build.
4. Start the game or server to generate the default files in `config/cobblemon_xp_overhaul/`.
5. Catch a Pokémon and complete a battle to observe the rewards.

::: info Source and public release
The source identifies **v2.0**. Check CurseForge for the actual published files before installing.
:::
