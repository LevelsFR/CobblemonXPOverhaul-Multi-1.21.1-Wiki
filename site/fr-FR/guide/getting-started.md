# Installation et prérequis

Cobblemon XP Overhaul ajoute des récompenses d'expérience configurables pour les captures et les combats, ainsi qu'une **fiole d'XP** pour entraîner les Pokémon.

## Versions prises en charge

| Composant | Version |
| --- | --- |
| Minecraft | **1.21.1** |
| Cobblemon XP Overhaul | **2.1** |
| Cobblemon | **1.8.2 minimum et strictement inférieure à 1.9.0**, sur Minecraft 1.21.1 |
| Mod loader | **Fabric** ou **NeoForge** |
| OS Cobblemon Library | **1.3.0+**, obligatoire |
| Java | **21** |

### Fabric

Installer la version **Fabric** du mod avec Fabric Loader **0.17.2+**, Fabric API, Fabric Language Kotlin **1.13.6+**, Cobblemon **1.8.2+ (avant 1.9)**, **OS Cobblemon Library 1.3.0+** et Cloth Config **15.0.140+**. Mod Menu est facultatif.

### NeoForge

Installer la version **NeoForge** du mod avec NeoForge **21.1.182+**, Cobblemon **1.8.2+ (avant 1.9)**, **OS Cobblemon Library 1.3.0+** et Cloth Config **15.0.140+** sur les clients utilisant l'interface de configuration. La compilation utilise Kotlin for Forge. Ne mélangez pas les fichiers Fabric et NeoForge.

## Mise en place

1. Préparer Minecraft 1.21.1 avec le loader choisi et Cobblemon.
2. Télécharger la version correspondante sur [CurseForge](https://www.curseforge.com/minecraft/mc-mods/cobblemon-xp-overhaul).
3. Placer le JAR et ses dépendances, notamment OS Cobblemon Library, dans `mods`. En multijoueur, serveur et clients doivent utiliser la variante adaptée.
4. Démarrer le jeu ou serveur pour générer `config/cobblemon_xp_overhaul/`.
5. Capturer un Pokémon, puis remporter un combat pour vérifier les récompenses.

::: info Version du code
Le dépôt source indique **v2.1**. Vérifiez sur CurseForge les fichiers réellement publiés.
:::

Pour obtenir un aperçu de transfert sans consommation, faire **Shift + clic droit** sur un Pokémon invoqué avec la fiole équipée en main. Lire la [progression](/fr-FR/guide/progression), la [fiole d'XP](/fr-FR/guide/xp-flask) et la [configuration](/fr-FR/guide/configuration).
