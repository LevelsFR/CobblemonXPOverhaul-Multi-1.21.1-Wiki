# Security policy

This repository contains **public documentation only**. The Cobblemon XP Overhaul source repository remains private.

## Vulnerability reports

**Do not post exploit details, credentials or internal code in a public GitHub issue or pull request.** When available, use **Security → Report a vulnerability** (private vulnerability reporting). Otherwise contact the maintainer privately by direct message through the [community Discord](https://discord.gg/kb8NSTF45n), not in a public Discord channel.

## Repository controls

- Maintainers review changes before merging.
- Pull request checks have read-only access and cannot deploy.
- GitHub Pages is built entirely from this public repository without private tokens or access to private sources.
- No private assets, backup files, credentials, private endpoints, compiled mod artifacts or build outputs belong here.
- The public-content check is a heuristic guardrail, not a substitute for review.

Repository administrators should enable branch rules for `main` (required reviews and checks, no force-push or deletion), secret scanning, push protection, and private vulnerability reporting where supported.
